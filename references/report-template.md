# 报告模板

输出顺序是"结论先行"。方括号里是填写说明，写报告时删掉。

各档位写哪些部分：
- **速览**：只写标 ⚡ 的部分（§0、§2、§3、§4.3 一句话时效性、§4.5、§7.3）。各章要点一行一章；§3 只写主要观点，概念表和金句可省。
- **标准**：全部章节；附录有内容才写。
- **深度**：全部章节和附录；时效性表格的关键条目要联网核实。

> **原书**：作者，*原书名*（出版年，出版社）
> **版本**：[译本信息：译者、出版社、年份；原版则省略]
> **解读模式**：速览 / 标准 / 深度 · [全文已读 / 抽读：目录、各章首尾、第X/Y章全文 / 概览模式：未提供原文]
> **来源标注**：【原文·位置】书中原文 · 【模型知识】未联网核实 · 【检索·来源】已核实 · 【推断】分析者推论

## 篇幅分配参考（标准档，总计 5000–9000 字）

| 部分 | 占比 |
|---|---|
| 0 速览 + 1 定位 | 10% |
| 2 结构 | 20% |
| 3 论点 | 10% |
| 4 证据与批判 | 35% |
| 5–6 坐标与关联 | 12% |
| 7 应用 | 10% |
| 附录 | 3% |

需要压缩时，先压缩各章要点和关联层，最后才动漏洞和时效性。
