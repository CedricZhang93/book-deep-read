# 六层分析指南

每一层都给出：要做什么、怎么做、常见陷阱。

## 目录
- 第0层 定位
- 第1层 结构
- 第2层 论点
- 第3层 证据
- 第4层 批判（漏洞、优缺点、时效性、立场）
- 第5层 坐标
- 第6层 应用

---

## 第0层 定位：这是本什么书

**要做什么**：作者是谁、什么时候写的、为什么写、写给谁看。

**怎么做**
- **作者想解决的问题**是理解全书的钥匙。去前言、引言、第一章和结语里找作者自己的说法，例如"我写这本书是因为……""市面上没有一本……"，并原文引用。很多书读不懂，是因为不知道它在跟谁对话、在反驳什么。
- **写作时间要写到年份**，并推断当时的语境：什么事件、什么争论正在发生。这一步直接决定了时效性检验要查什么。
- **作者自述的立场**要记下来，在第4层和实际立场做对比。
- 注意版本差异：中译本书名经常是营销包装（例如加上"斯坦福""哈佛"），要和原书名对照；中译本可能被拆分成上下册；可能是改版书。

**陷阱**
- 作者背景只写头衔，没写和本书相关的那部分经历。
- 把推荐序或导读的评价当成作者的观点。

---

## 第1层 结构：书里说了什么

**要做什么**：框架图 + 各章要点。

**怎么做**
- **框架图**要显示章节之间的**逻辑关系**（总分、递进、并列、问题→方案），而不是目录的翻版。可以用 ASCII 树状图或流程图。
- 找出**贯穿全书的暗线**：在多个章节里反复出现的概念、模型或论点。这往往是作者真正的思想骨架，也是普通总结最容易漏掉的东西。
- **各章要点**用表格，每章 1–3 句话，写"这章论证了什么"，而不是"这章讨论了什么"。
  - ❌ "第5章讨论贸易余额"
  - ✅ "第5章：贸易逆差本质上是资本净流入，与贸易是否公平无关"
- 章节很多（超过 20 章）时，可以按部分合并。

**陷阱**
- 要点写成主题清单，没有观点。
- 漏掉作者在章节结尾的总结性论断，那往往才是该章的结论。

---

## 第2层 论点：作者主张什么

**要做什么**：一句话核心观点、主要观点排序、关键概念表、原文金句。

**怎么做**
- **一句话核心观点**必须是一个可以被反驳的**主张**，不能只是主题。
  - ❌ "本书介绍了宏观经济学"
  - ✅ "长期生活水平由供给侧生产率决定，短期波动靠需求管理缓冲"
  - 检验方法：有没有一个理性的人会不同意这句话？如果没有，说明它还不是主张。
- 区分**实质主张**和**方法论主张**（比如"经济学是框架而不是答案"）。两者都写，但核心观点优先写实质主张。
- **主要观点**按重要性排序（不是按章节顺序），5–8 条，标出所在章节。标出全书**最反直觉、最有特色**的那一条。
- **关键概念表**：概念 / 一句话解释 / 所在章节。只收录理解本书必需的概念，10–15 个为宜。
- **原文金句**：5–8 句，必须是原文逐字引用，标章节。选能代表核心观点、或者表达特别精彩的句子。

**陷阱**
- 把作者转述的别人的观点当成作者本人的观点。
- 金句凭记忆写，与原文不一致。在有原文的情况下，引文必须从提取文本中复制。

---

## 第3层 证据：凭什么这么说

**要做什么**：核心论证链、证据类型和质量、引用文献的原始出处。

### 论证链拆解
把核心观点的论证写成**前提→结论**的链条：

```
P1 [前提/证据]（第X章，证据类型）
P2 [前提/证据]（第Y章，证据类型）
   → [中间结论]
P3 ...
────────
结论：...
```

用**钢人原则**：用作者最强的版本复述论证，补上作者隐含但合理的前提。写完后自问：作者看了会不会说"对，我就是这么论证的"？

### 证据类型与评级

| 类型 | 一般强度 | 注意 |
|---|---|---|
| 数学推导、定义、恒等式 | 强（在其适用范围内） | 恒等式不能直接给出因果 |
| 随机对照实验、元分析 | 强 | 看是否能复现、样本是否代表目标人群 |
| 大样本统计或计量研究 | 中到强 | 相关不等于因果，留意选择偏差和反向因果 |
| 官方统计数据 | 中到强 | 看时间范围和覆盖地区 |
| 历史案例 | 中 | 单一案例、挑选有利案例的问题 |
| 专家观点或权威引用 | 弱到中 | 诉诸权威 |
| 个人经验或轶事 | 弱 | 幸存者偏差 |
| 类比和思想实验 | 用于说明，不构成证据 | 类比在哪里失效 |

用表格列出书中的关键证据，加上 ★1–5 评级和简短说明。最后给一句**整体判断**（例如"解释型而非论证型写作，几乎不注出处"）。

### 引用文献索引
把书中提到的研究、报告、人物观点列成表：引用内容 / 位置 / 原始出处。书中经常只写"某大学研究发现"，要尽量补全原始出处（作者、标题、年份、期刊）。补全的信息标 `【模型知识】` 或 `【检索】`。如果发现书中的转述和原始研究不一致（数字、年份、结论），单独指出。

### 技术和原理
如果书中涉及技术、模型或理论，用 2–4 句话讲清它的**基本原理**，再说明作者是怎么用它的。不要只写名字。

## 第4层 批判：说得对不对

这是最有价值的一层，也是最容易写空的一层。

### 4.1 论证漏洞

逐一检查下面这些常见漏洞。**只写确实存在的**，每条都要指向具体章节和具体论证步骤。

| 漏洞类型 | 检查问题 |
|---|---|
| 作者自承的缺口 | 作者在哪里承认"尚无定论""没有找到……"？结论是否仍然建立在这个缺口上？（这是最有力的批判，因为用的是作者自己的话） |
| 前后矛盾 | 不同章节之间有没有互相冲突的说法？ |
| 相关推因果 | 两件事同时发生，就被说成一件导致另一件？ |
| 后此谓彼 | 事件 A 之后发生了 B，就说 A 导致了 B？同期有没有别的原因？ |
| 反向因果 | 会不会是结果导致了原因？ |
| 选择偏差 / 幸存者偏差 | 样本是怎么选的？失败案例去哪了？ |
| 挑选案例 | 正反各只举一例，而且恰好都支持结论？ |
| 单因解释 | 复杂现象被归结为一个原因，其他同时存在的原因被忽略？ |
| 样本局限 | 证据只来自某个国家、某个时期，结论却被说成普遍规律？ |
| 诉诸权威 | 关键步骤靠名人名言或"主流共识"支撑？ |
| 定义滑移 / 偷换概念 | 同一个词在不同地方意思不同？ |
| 把恒等式或定义当成发现 | 例如增长核算中的"技术贡献"其实是残差 |
| 稻草人 | 作者反驳的对立观点，是不是对方真正的观点？ |
| 平均值掩盖分布 | 总体影响很小，不等于对局部人群影响小 |
| 循环论证 | 结论被偷偷用作前提？ |
| 英雄叙事 | 只讲预言对了的人，忽略同期同样预言过的人或预言错了的人 |

漏洞的写法：

```
**漏洞 N：一句话标题**
[具体章节]的[具体论证]……问题在于……[对照的证据或反例，标来源]。
```

### 4.2 优点与缺点
- 优点和缺点各 4–6 条，每条都要**具体**。
  - ❌ "语言通俗"
  - ✅ "用雅浦岛石币解释货币的本质是记账，比直接给定义好懂"
- 缺点里要包括**遗漏**：这个领域在今天公认重要、而本书没讲的议题。

### 4.3 时效性检验
对出版超过 3 年、或者涉及快速变化领域的书**必做**。

做一张表：书中说法（标章节）/ 后来的发展（标来源）/ 影响程度。影响程度：
- 🔴 已过时，或被重要的新证据推翻
- 🟠 需要更新
- 🟡 书中原本就不准确
- 🟢 预测被验证
- ⚪ 仍在演变

重点查：书中的数据和预测、政策和制度描述、引用的研究有没有复现失败或被修正、作者自己后来有没有改变看法。

### 4.4 自称立场与实际立场
很多书自称"客观""中立""不站队"。把作者的自述和书中实际表现出的立场做对比：在哪些争议议题上，作者明确选了边？这些选择合在一起，属于哪种立场？

"处在中间位置"也是一种立场。推荐序、书评中来自不同方向的批评可以作为佐证：两边都批评，说明它在中间。

## 第5层 坐标：在知识地图上的位置

**所属学派**：说明它代表哪个学派、哪个时代的哪种共识，以及这个学派的核心信条。如果作者跨学派，指出具体在哪些问题上倾向哪一派。

**对立观点表**：方向 / 学派或代表人物 / 与本书的分歧 / 推荐阅读。
- 至少覆盖两个方向（例如"更信市场"和"更重干预"、"更乐观"和"更悲观"）。
- 不要只列一个笼统的"反方"。
- 优先列出在**本书具体论点**上针锋相对的作品，而不只是大方向相反的作品。
- 推荐阅读必须是真实存在的书或论文，书名和作者要准确。不确定时标 `【模型知识】`，深度档需要检索核实。

**关联**
- 本领域：前承（它继承或反驳了谁）、同类书比较、读后延伸阅读。
- 跨领域：这本书的概念在哪些其他领域有对应或可以迁移。
- 名字容易混淆的人物和概念，顺手辨析。

---

## 第6层 应用：对我有什么用

- **生活应用**按场景组织（看新闻、理财、工作、人际关系、公共讨论……），每个场景写**可以直接用上的具体概念或判断方法**。
- **行动清单** 3–6 条，具体到可执行：查什么数据、检查什么、读哪本书来补短板。
- **怎么读**：必读章节、可以快速浏览的章节、可以跳过的章节（并说明原因，比如已过时、和别的章节重复）、建议搭配阅读的材料。
- **适合谁、不适合谁**。
- **自测题** 4–6 道：要考查理解和迁移，而不是记忆。至少一道题要求读者评价书中的某个论证。
