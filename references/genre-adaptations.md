# 不同类型文本的调整

六层框架默认适用于**论证型非虚构**（社科、商业、科普、观点类书籍）。其他类型按下表调整各层的权重和做法。

## 技术书、教材
- **证据层加重**：对每个核心技术或方法，讲清基本原理（解决什么问题 → 怎么做 → 关键假设 → 局限），再说明书里怎么用它。
- **引用索引加重**：技术的原始论文、标准、开源项目都要列出。
- **时效性必做**：技术迭代快，标出哪些 API、工具、最佳实践已经过时，并说明现在通行的替代方案。速览档至少写一句（例如“2025 年出版，框架和概念仍适用，代码示例依赖的某库已改版”）；完整的时效性表格留给标准档和深度档。
- **学派层改为“技术路线对比”**：同一个问题有哪些主流方案，本书选了哪条路线，为什么；再列 2–3 本走其他路线或侧重点不同的同类书，方便读者比较。
- **应用层**改为"动手清单"：可以复现的练习、可以直接用到项目里的做法。
- 结构层可以加一张**前置知识**表：读这本书之前需要会什么。

## 学术论文
- 结构层改为论文结构：研究问题 / 方法 / 数据 / 主要发现 / 结论。
- **证据层是重点**：研究设计（实验、准实验、观察、模型）、样本量和代表性、识别策略、稳健性检验、效应大小（而不只是是否显著）。
- 批判层重点看：内部效度、外部效度、可复现性、结论是否超出了数据能支持的范围。如果有 scientific-critical-thinking skill，可以借用它的评价框架。
- 坐标层：这篇论文在文献中的位置，它回应了谁，后来被谁引用、支持或反驳。深度档要检索后续引用。
- 应用层弱化，改为"对实践或政策的含义"。

## 长篇文章、评论
- 默认用速览档或精简的标准档，篇幅 1500–4000 字。
- 结构层按段落或小节组织，不需要框架图，除非文章很长。
- 时效性：看文章发表时间和讨论的事件，后来有没有新进展。
- 重点检查修辞手法：标题和正文是否一致、有没有用情绪化语言代替论证、引用的数据有没有出处。

## 历史、传记、叙事型非虚构
- 结构层：时间线加关键转折点。
- 论点层改为"作者的史观或解释框架"：作者如何解释事件的因果？强调个人、制度、经济还是文化？
- 证据层：史料来源（一手还是二手、档案、口述）、作者对史料的取舍。
- 批判层：重点看叙事偏向（谁的视角被放大，谁被忽略）、事后诸葛（用结局倒推当时的选择）、传主美化。
- 坐标层：同一事件或人物的其他重要著作，以及它们的解释有何不同。

## 自助、成长、心理学大众读物
- 证据层特别重要：书中的心理学研究**有没有复现**。很多经典效应（启动效应、自我损耗、权力姿势等）在复现危机中失败或被大幅削弱，深度档要检索。
- 区分"有研究支持的建议"和"作者的个人经验"。
- 批判层重点看：幸存者偏差（成功人士的做法不一定是他们成功的原因）、不可证伪的主张、把相关说成因果。
- 应用层是重点，但要标明哪些建议证据较强。

## 访谈录、对话体、文集
访谈和对话的思想是散的：同一个观点会在不同场次里反复出现，每次说法略有不同；章节只是谈话的时间顺序，不是论证顺序。所以照搬“各章要点”会把思想切碎，要先重组再分析。

- **结构层用“议题地图”代替逐章要点**：把散落在各场对话里的同一议题合并，每个议题写清楚核心论断、主要出处（用 `--- [小节] ---` 定位）、在不同场次之间有没有变化。各场次的概况用一张简短的表交代即可。
- **论点层写“一个总主张 + 3 个左右主要议题”**：一句话核心观点要概括贯穿各议题的那条主线，而不是挑一个议题。
- **证据层改为“思想骨架”**：访谈很少有严格的前提→结论推理，更适合拆成三层：
  - 诊断：受访者认为世界或这个领域出了什么问题
  - 方法：他主张用什么方式去看、去做
  - 姿态：他对知识、行动、自身位置的基本态度
  再看三层之间是否自洽。
- **区分说话人**：受访者、提问者（以及文集里的不同作者）的观点分开标注。提问者的提问方式本身也是信息：他引向了哪些话题、回避了哪些。
- **批判层重点看口语表达特有的问题**：
  - 即兴判断：随口举的例子、未经核实的数字和断言，不能当作作者深思熟虑的结论来批，但要指出读者不该直接引用
  - 概念漂移：同一个词在不同场次里意思不同
  - 追问是否充分：提问者有没有在关键处追问，还是让模糊的说法轻易过关
  - 自我修正：受访者在后面的对话里是否修正或推翻了前面的说法（这很有价值，要专门指出）
- **文集**：先给每篇文章一行定位，再找各篇之间的共同主张和内部分歧。

## 译本
- 中译本书名和原书名对照；拆分版、改版要说明。
- 导读、推荐序、译者注、审订说明和正文分开处理。
- 附录 B 记录翻译疑点：术语误译、数字或年份错误、意思反了的译法（例如政治光谱术语在不同语境下含义相反）。

## 不适用的类型
小说、诗歌、戏剧等纯文学作品不适用本框架（例如"论证漏洞"没有意义）。遇到这类请求时，告诉用户这个 skill 针对非虚构，然后按常规方式做文学赏析：主题、人物、结构、手法、语境。
